# moneychat.pro

Статический сайт приложения: лендинг, политика конфиденциальности и условия использования.
Раздаётся через GitHub Pages на домене `moneychat.pro` (файл `CNAME`).

Политика и условия обязательны для App Store и Google Play: если страницы недоступны,
приложение снимают с публикации. Поэтому здесь нет сборки, зависимостей и бэкенда —
три HTML-файла и один CSS, которые невозможно сломать деплоем.

```
index.html        лендинг
privacy/          политика конфиденциальности → moneychat.pro/privacy
terms/            условия использования → moneychat.pro/terms
styles.css        общее оформление, палитра и шрифты как в приложении
CNAME             домен для GitHub Pages
```

Адреса `/privacy` и `/terms` зашиты в приложение (`--dart-define` в `codemagic.yaml`)
и указаны в карточках обоих магазинов — менять пути нельзя.
